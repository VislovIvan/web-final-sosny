# Сосны: бронирование домов на Ладоге

Итоговая практическая работа по курсу «Веб-дизайн», СПбГУПТД. Вислов Иван, группа 5-МВ-5.

Сайт: https://vislovivan.github.io/web-final-sosny/
Репозиторий: https://github.com/VislovIvan/web-final-sosny

Учебный сайт вымышленной базы отдыха «Сосны» на берегу Ладожского озера. Путь пользователя: найти дом, выбрать, оформить бронь, увидеть её в «Моих бронях» и отменить.

## Страницы и ветки

Работа индивидуальная по решению преподавателя: Вислов Иван делает каркас как лид и все страницы сам, каждую в своей ветке с запросом на слияние в `main`.

| Страница | Что на ней | Ветка |
|---|---|---|
| `index.html` | главная: о базе, подбор отдыха | `main` (каркас) |
| `catalog.html` | схема базы, список домов, фильтры, даты | `feature/catalog` |
| `booking.html` | форма брони, сумма, проверка дат | `feature/booking` |
| `orders.html` | мои брони, отмена, сброс демо | `feature/orders` |
| `index.html`, `booking.html` | погода на базе и прогноз на даты поездки | `feature/weather` |
| все страницы | исправления после общей проверки | `fix/review` |

## Общие договорённости

- ID домов от `h1` до `h10`, данные домов только в `js/data.js`.
- Брони лежат в одном ключе localStorage `sosny.bookings.v1`, читать и менять их можно только через `js/storage.js`.
- Запись брони: номер `С-0001`, `houseId`, `from` (дата заезда YYYY-MM-DD), `nights`, `guests`, `total`, `status`.
- Общий вид задают `mac.css` и `css/common.css`; у каждой страницы свои `css/<страница>.css` и `js/<страница>.js`.
